# 🛰️ Zentinel — Sistema Inteligente de Monitoreo Urbano

**Zentinel** es una plataforma moderna diseñada para analizar, mapear y gestionar la actividad de pandillas, incidentes y zonas de riesgo dentro de una ciudad.  
Combina **PHP + MySQL + Google Maps + Telegram Bot** para ofrecer una herramienta visual, rápida y profesional.

---

## 🗺️ Características Principales

- 🌐 **Mapa interactivo** profesional con marcadores avanzados.  
- 🔥 **Mapa de calor** para visualizar concentración de incidentes.  
- 🎯 **Filtros por zona**: Norte, Sur, Oriente, Poniente y Centro.  
- 📍 **Autocompletado estilo Google Maps** para seleccionar ubicaciones en tiempo real.  
- 👁️ **Visualización instantánea** de pandillas registradas.  
- 📌 Marcadores detallados: peligrosidad, integrantes, zona, ubicación.  
- 🧠 Identificación rápida de **patrones delictivos** y zonas críticas.

---

## 🧩 Gestión Completa de Pandillas

- 📝 Registro, edición y eliminación.  
- 👤 Campo editable de **líder**, sin restricciones.  
- 📋 Datos completos: descripción, zona, integrantes, edades, horario, ubicación.  
- 🚨 **Delitos asociados** y faltas cometidas con selección rápida.  
- 🌐 Redes sociales / alias.  
- 📍 **Pin de ubicación arrastrable** dentro de Google Maps.

---

## 📊 Panel Administrativo

- 🔐 Control de acceso para **Admin y Consultor**.  
- 📈 Dashboard con estadísticas:  
  - Total de pandillas  
  - Total de integrantes  
  - Total de eventos registrados  
- 🌙 Interfaz **oscura, moderna y profesional**.

---

## 🚨 Gestión de Eventos

- Registro de eventos: riñas, delitos, faltas, incidentes críticos.  
- Marcadores con **popup avanzado**.  
- Integración directa con **mapa de calor**.

---
